Учебный проект: два Java Spring Boot микросервиса взаимодействуют по HTTP с помощью RestTemplate, React-интерфейс показывает результат.

Элементы проекта
================

1. greeting-service (порт 8081)
   Второй микросервис. Endpoint GET /api/greeting?name=Анна возвращает JSON с приветствием.
   Исходный код: greeting-service/src/main/java/com/example/greeting/
   Сборка: Gradle Kotlin DSL, build.gradle.kts.

2. orchestrator-service (порт 8080)
   Первый микросервис и API для фронтенда. Endpoint GET /api/message?name=Анна вызывает greeting-service с помощью Spring RestTemplate и возвращает его ответ.
   RestTemplate создаётся в RestTemplateConfig.java, вызов находится в MessageService.java.
   URL второго сервиса настраивается свойством clients.greeting-service.url; переменная окружения GREETING_SERVICE_URL может его переопределить.
   Сборка: Gradle Kotlin DSL, build.gradle.kts.

3. frontend (порт 5173)
   Клиент на React, TypeScript и Vite 7. Форма отправляет запрос GET /api/message в orchestrator-service и отображает полученное приветствие.

4. compose.yaml
   Конфигурация Docker Compose для запуска всех трёх приложений.

Запуск всех приложений через Docker
===================================

Требуются Docker и Docker Compose. Из корня репозитория выполните:

docker compose up --build

Откройте в браузере: http://localhost:5173

Остановка: нажмите Ctrl+C, затем выполните:

docker compose down

Запуск без Docker
=================

Требуются JDK 17+, Gradle 8.10+ и Node.js 20.19+ (или 22.12+).

Терминал 1 — greeting-service:

cd greeting-service
gradle bootRun

Терминал 2 — orchestrator-service:

cd orchestrator-service
gradle bootRun

Терминал 3 — React frontend:

cd frontend
npm install
npm run dev

Откройте http://localhost:5173. Для локального запуска orchestrator-service по умолчанию обращается к http://localhost:8081.

Про��ерка API
============

Получить ответ второго микросервиса напрямую:

curl 'http://localhost:8081/api/greeting?name=Анна'

Получить ответ через первый микросервис (внутри он вызовет RestTemplate):

curl 'http://localhost:8080/api/message?name=Анна'

Ожидаемый JSON:

{"message":"Привет, Анна! Ответ от greeting-service."}

Путь запроса
============

Браузер → React/Vite → orchestrator-service → RestTemplate → greeting-service → ответ обратно в React.

База данных не используется. RestTemplate выполняет синхронный HTTP-вызов: поток orchestrator-service ожидает ответ greeting-service.

Стек backend: Java 17, Spring Boot, Gradle Kotlin DSL, RestTemplate. Frontend оставлен на исходном React + TypeScript + Vite 7.
